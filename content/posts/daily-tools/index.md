## Ghostty

[Ghostty](https://ghostty.org/) 是 Mitchell Hashimoto（HashiCorp 创始人）用 Zig 编写的开源终端模拟器。它通过 GPU 加速渲染，在 macOS 和 Linux 上使用原生 UI，开箱即用，几乎不需要配置。

以下快捷键均为 macOS 下的默认值（基于 1.3），`⌘` 在 Linux 下通常对应 `Ctrl+Shift`。

### 分屏

不用 tmux，也能在一个窗口里并排开多个终端。

| 快捷键        | 作用                               |
| ------------- | ---------------------------------- |
| `⌘D`          | 向右分屏                           |
| `⌘⇧D`         | 向下分屏                           |
| `⌘[` / `⌘]`   | 切换到上一个 / 下一个分屏          |
| `⌘⌥ + 方向键` | 按方向切换分屏                     |
| `⌘⌃ + 方向键` | 调整分屏大小                       |
| `⌘⌃=`         | 均分所有分屏                       |
| `⌘⇧↩`         | 放大 / 还原当前分屏，临时专注一个  |
| `⌘W`          | 关闭当前分屏（或标签页）           |

### 标签页与窗口

| 快捷键          | 作用                                |
| --------------- | ----------------------------------- |
| `⌘T`            | 新建标签页                          |
| `⌘1` ~ `⌘8`     | 跳到第 N 个标签页                   |
| `⌘9`            | 跳到最后一个标签页                  |
| `⌘⇧[` / `⌘⇧]`   | 上一个 / 下一个标签页               |
| `⌘Z` / `⌘⇧T`    | 撤销关闭，误关的标签页和分屏能找回  |
| `⌘↩`            | 切换全屏                            |

### 输出与滚动

| 快捷键        | 作用                                                 |
| ------------- | ---------------------------------------------------- |
| `⌘↑` / `⌘↓`   | 跳到上一条 / 下一条命令的提示符，快速翻看长输出      |
| `⌘K`          | 清屏（连同滚动历史一起清掉）                         |
| `⌘F`          | 在滚动历史中搜索，`⌘G` / `⌘⇧G` 切换匹配项            |
| `⌘E`          | 用选中的文字直接搜索                                 |
| `⌘Home` / `⌘End` | 滚动到顶部 / 底部                                 |
| `⌘⇧J`         | 把当前屏幕内容存成文件，并把路径粘贴到命令行         |

跳转提示符依赖 shell integration。bash、zsh、fish 下 Ghostty 会自动注入，通常无需额外设置。

### 其他

| 快捷键   | 作用                                         |
| -------- | -------------------------------------------- |
| `⌘⇧P`    | 命令面板，忘了快捷键时直接搜索动作名         |
| `⌘,`     | 打开配置文件                                 |
| `⌘⇧,`    | 重新加载配置，改完立即生效                   |
| `⌘=` / `⌘-` / `⌘0` | 放大 / 缩小 / 重置字号             |

### 值得加的配置

配置文件位于 `~/.config/ghostty/config`：

```ini
# 全局快捷键呼出下拉式终端（Quick Terminal），类似 iTerm2 的 Hotkey Window
# 首次使用需在系统设置中授予辅助功能权限
keybind = global:cmd+grave_accent=toggle_quick_terminal

# 跟随系统深浅色自动切换主题
theme = light:Catppuccin Latte,dark:Catppuccin Mocha

# 让 Option 键作为 Alt 使用，方便 shell 和 Vim 里的 Alt 组合键
macos-option-as-alt = true
```

### 自带的命令行工具

| 命令                                  | 作用                                   |
| ------------------------------------- | -------------------------------------- |
| `ghostty +list-themes`                | 交互式预览并挑选内置主题               |
| `ghostty +list-keybinds --default`    | 列出所有默认快捷键                     |
| `ghostty +show-config --default --docs` | 列出所有配置项及说明                 |
| `ghostty +list-fonts`                 | 列出可用字体                           |

## Emacs

Emacs 的功能大致可以分成这几块：

- **基础操作**：按键写法、缓冲区与窗口、帮助系统，是使用其他所有功能的前提
- **Org mode**（内置）：用纯文本写大纲，并在此基础上发展出一整套工具
  - 待办与日程：用 TODO、优先级、标签和日期管理任务，Agenda 能把多个文件里的任务汇总到一处查看
  - Capture：随时把想法或任务记到指定文件，不打断手头的工作
  - Babel：在笔记中嵌入并运行代码块，类似 Jupyter Notebook，但支持几乎所有编程语言
  - org-roam（第三方包）：用双向链接组织笔记，类似 Obsidian
- **Magit**（第三方包）：Git 客户端，被公认为 Emacs 的杀手级应用，终端里的 Lazygit 与它思路相近
- **TRAMP**（内置）：像编辑本地文件一样，直接编辑远程服务器或容器里的文件
- **Dired**（内置）：文件管理器，可以先标记多个文件，再批量重命名、移动或删除，终端里的 yazi 与它类似

另外，[Doom Emacs](https://github.com/doomemacs/doomemacs) 并不是某项功能，而是一套预先配好的 Emacs 发行版（同类的还有 Spacemacs）。它集成了上面这些包，并默认启用 Vim 风格的按键，适合不想从零开始折腾配置的人。用过 LazyVim 的话会很容易上手：两者都以空格作为 leader 键，按下后会弹出菜单，提示接下来可以按哪些键。

### 基础操作

#### 按键写法

Emacs 文档里的按键用缩写表示，对应关系如下：

| Emacs 写法 | Windows / Linux | macOS                |
| ---------- | --------------- | -------------------- |
| `C-x`      | `Ctrl+x`        | `Ctrl+x`             |
| `M-x`      | `Alt+x`         | `Option+x`           |
| `S-`       | `Shift`         | `Shift`              |
| `RET`      | `Enter`         | `Return`             |
| `SPC`      | 空格            | 空格                 |

`C-x C-s` 表示先按 `Ctrl+x`，松开后再按 `Ctrl+s`。macOS 终端里要让 `Option` 充当 `Meta`，需要打开终端的相应设置（Ghostty 即上面的 `macos-option-as-alt = true`）。

#### 前缀键

Emacs 的快捷键大多由前缀键开头，可以把前缀理解成一级「菜单」，按下后再选具体操作。

`C-x` 下是文件、窗口和缓冲区（buffer，大致可以理解为打开的文件）相关的操作：

| 按键      | 作用                                  |
| --------- | ------------------------------------- |
| `C-x C-f` | 打开文件（find file）                 |
| `C-x C-s` | 保存（save）                          |
| `C-x C-w` | 另存为（write）                       |
| `C-x C-c` | 退出 Emacs                            |
| `C-x b`   | 切换缓冲区（buffer）                  |
| `C-x k`   | 关闭缓冲区（kill buffer）             |
| `C-x 2`   | 上下拆分窗口                          |
| `C-x 3`   | 左右拆分窗口                          |
| `C-x 0`   | 关闭当前窗口                          |
| `C-x 1`   | 只保留当前窗口                        |

`C-c` 通常留给各个模式和插件使用，后面 Org mode 的快捷键大多以它开头。

#### 不用死记，让 Emacs 自己告诉你

Emacs 内置了完整的帮助系统，忘了就查，这是最值得记住的一组键：

| 按键                 | 作用                                 |
| -------------------- | ------------------------------------ |
| `C-h k`，再按某个键  | 查看这个键执行什么命令               |
| `C-h w`，再输入命令名 | 查看这个命令绑定在哪个键上          |
| `C-h b`              | 列出当前所有按键绑定                 |
| `M-x`，再输入命令名  | 不记得快捷键时，直接按名字执行命令   |

#### 常用操作

| 按键                   | 作用                                             |
| ---------------------- | ------------------------------------------------ |
| `C-g`                  | 取消当前操作，按错键时先按它                     |
| `C-/` / `C-x u`        | 撤销                                             |
| `C-n` / `C-p`          | 下一行 / 上一行                                  |

### Org mode

[Org mode](https://orgmode.org/) 文件以 `.org` 结尾，用 `*` 的个数表示标题层级，下面所有功能都建立在这个大纲结构上。

#### 大纲

| 按键                   | 作用                                             |
| ---------------------- | ------------------------------------------------ |
| `TAB`（光标在标题上）  | 折叠 / 展开当前标题                              |
| `S-TAB`                | 整个文件在「全部折叠 / 只看标题 / 全部展开」间切换 |
| `M-RET`                 | 在下方新建一个同级标题                       |
| `M-→` / `M-←`           | 把标题降一级 / 升一级                        |
| `M-↑` / `M-↓`           | 把整个标题（连同子项）上移 / 下移            |

#### 待办

| 按键                    | 作用                                         |
| ----------------------- | -------------------------------------------- |
| `C-c C-t` 或 `S-→` / `S-←` | 在 `TODO` → `DONE` → 无 之间循环切换      |
| `C-c ,` 然后 `A` / `B` / `C` | 设置优先级，按 `SPC` 则删除优先级       |
| `C-c C-q`               | 给当前标题设置标签，输入后按 `RET`（子标题会继承标签） |

#### 稀疏树

稀疏树（sparse tree）会折叠掉无关内容，只露出匹配的任务。

| 按键       | 作用                           |
| ---------- | ------------------------------ |
| `C-c / t`  | 只显示所有 `TODO` 任务         |
| `C-c / m`  | 按标签或条件筛选，写法见下表   |
| `C-c C-c`  | 清除筛选留下的高亮             |
| `S-TAB`    | 重新展开整个文件               |

`C-c / m` 的筛选写法：

| 输入              | 含义                                          |
| ----------------- | --------------------------------------------- |
| `紧急`            | 带「紧急」标签                                |
| `电脑+紧急`       | 同时带这两个标签                              |
| `电脑\|手机`      | 带其中任意一个标签                            |
| `电脑-紧急`       | 带「电脑」但不带「紧急」                      |
| `PRIORITY="A"`    | 优先级为 A                                    |
| `+紧急/TODO`      | 带「紧急」且状态仍是 `TODO`（排除已完成的）   |

> 稀疏树只作用于当前文件；要跨多个文件筛选，需要用 Agenda。

#### 日期

Org 的任务日期分两种：`SCHEDULED`（计划哪天开始做）和 `DEADLINE`（最晚哪天完成）。

| 按键            | 作用                        |
| --------------- | --------------------------- |
| `C-c C-s`       | 设置计划日期（SCHEDULED）   |
| `C-c C-d`       | 设置截止日期（DEADLINE）    |
| `C-u C-c C-s`   | 删除计划日期                |
| `C-u C-c C-d`   | 删除截止日期                |
| `C-c .`         | 插入活动时间戳 `<...>`，会出现在 Agenda 里 |
| `C-c !`         | 插入非活动时间戳 `[...]`，只做记录，不会出现在 Agenda 里 |

弹出日期选择后，可以直接输入简写（假设今天是 2026-09-29 周二）：

| 输入             | 结果                    |
| ---------------- | ----------------------- |
| `.` 或直接 `RET` | 今天                    |
| `+1`             | 明天                    |
| `+3`             | 3 天后                  |
| `+2w`            | 2 周后                  |
| `fri`            | 下一个周五（10-02）     |
| `10-15`          | 今年 10 月 15 日        |
| `10-1 14:00`     | 10 月 1 日下午 2 点     |
| `+1 9:30`        | 明天早上 9:30           |

##### 重复任务

在日期后面加上重复标记，任务标记为 `DONE` 时会自动顺延到下一次，例如 `SCHEDULED: <2026-10-05 Mon +1w>`。

| 标记    | 下次日期怎么算                                     | 适合                             |
| ------- | -------------------------------------------------- | -------------------------------- |
| `+1w`   | 在原日期上加 1 周；漏了几次就要逐次补完             | 每次都不能落下的事，例如周报     |
| `++1w`  | 在原日期上按周往后推，直到落在今天之后（星期几不变）| 漏了就算了、不用补的事，例如周日倒垃圾 |
| `.+1w`  | 从完成那天起算 1 周后                              | 间隔比日期重要的事，例如理发、换床单 |

> 单位：`h` 小时、`d` 天、`w` 周、`m` 月、`y` 年。
  

##### 提前提醒

在 `DEADLINE` 后面加 `-3d`，Agenda 会从截止日前 3 天开始提醒（默认是提前 14 天）。可以和重复标记一起用：

```org
DEADLINE: <2026-10-15 Thu +1m -3d>
```

表示每月 15 日截止，每次提前 3 天提醒。

#### Agenda

Agenda 会扫描指定的 Org 文件，把其中的任务按日期汇总到同一个视图里，告诉你今天和这周要做什么。

要扫描哪些文件由 `org-agenda-files` 决定。原生 Emacs 默认没有给 Agenda 绑定快捷键，官方手册推荐绑定到 `C-c a`，下文沿用这个绑定：

```elisp
(setq org-agenda-files '("~/org/"))  ; 扫描该目录下所有 .org 文件
(global-set-key (kbd "C-c a") #'org-agenda)
```

按 `C-c a` 会弹出菜单，常用的是 `a`（本周日程）和 `t`（所有 TODO 列表）。进入 Agenda 后，可以直接用单个按键操作。

##### 浏览

| 按键         | 作用                                   |
| ------------ | -------------------------------------- |
| `n` / `p`    | 下一行 / 上一行                        |
| `f` / `b`    | 往后 / 往前翻一页（按周显示时即一周）  |
| `.`          | 回到今天                               |
| `d` / `w`    | 切换成按天 / 按周显示                  |
| `j`          | 跳到指定日期                           |
| `r` 或 `g`   | 刷新，在原文件里改过内容后使用         |
| `q`          | 退出 Agenda                            |

##### 操作任务

| 按键                    | 作用                                                 |
| ----------------------- | ---------------------------------------------------- |
| `t`                     | 切换 TODO 状态，相当于原文件里的 `C-c C-t`           |
| `,`                     | 设置优先级                                           |
| `:`                     | 设置标签                                             |
| `C-c C-s` / `C-c C-d`   | 设置计划日期 / 截止日期                              |
| `>`                     | 把任务改到另一天，按提示输入新日期（今天做不完时常用） |
| `S-→` / `S-←`           | 把任务往后 / 往前挪一天（终端不识别这两个键时，改用 `>`） |
| `RET`                   | 在当前窗口跳到原文件里的这条任务                     |
| `TAB`                   | 在另一个窗口打开原文件，光标也跳过去                 |
| `SPC`                   | 在另一个窗口显示原文件，光标仍留在 Agenda 里         |

##### 筛选

| 按键 | 作用                                       |
| ---- | ------------------------------------------ |
| `/`  | 按标签筛选，例如只看带「电脑」标签的任务   |
| `\|` | 清除所有筛选                               |

##### 每日用法

1. 早上按 `C-c a a`，看看今天要做什么、哪些截止日期快到了。
2. 今天做不完的任务，按 `>` 改到别的日子，别让它一直堆在过期列表里。
3. 做完一件，就在 Agenda 里按 `t` 标记完成。
4. 每周按一次 `C-c a t`，把所有 TODO 过一遍，给该做的任务排上日期。

#### Capture
