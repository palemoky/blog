好的翻译讲究信、达、雅，让读者望文生义、一目了然；而糟糕的翻译则南辕北辙，令人不知所云。技术领域尤为如此——一个生硬的译名，往往比原文更难理解。

## 糟糕的翻译

- **抬头**（title）：title，原指发票的接收方名称。"抬头"本是汉语中"抬起头"的动作，与"接收方"毫无关联，初次接触的人往往一头雾水。
- **缺省值**（default）：译者本意是"缺少、省略"的含义，但"缺省"二字生僻拗口，大多数人看到后难以立刻反应。相比之下，**默认值**的表达更自然、更直观。
- **鲁棒性**（robust）："鲁棒"是纯粹的音译，既无字面意义，又无联想空间，堪称技术翻译中的反面典型。**健壮性**才是更贴切的表达——既传达了"稳健、不易崩溃"的含义，又符合中文构词习惯。
- **宏**（macro）：英文中的 macro 与 micro 相对，"宏"字在中文里多与"宏大、宏观"相关联，无法准确传达其技术含义。更棘手的是，"宏"在不同场景下的行为差异显著，一个模糊的译名更加重了理解负担：

  | 场景         | 行为                 |
  | ------------ | -------------------- |
  | Vim / Office | 操作录制与回放       |
  | C 语言       | 编译期代码模板替换   |
  | Rust         | 语法层面的代码展开器 |

- **内存**（memory）：memory 的核心特性是易失性——断电即清空，与硬盘的持久存储截然不同。但"内存"仅强调"机器内部的存储"，完全遮蔽了这一关键属性。台湾用**记忆体**则体现了数据的临时性。
- **接口**（interface）：interface 的字面意思是"交界面"，描述的是两个系统之间的交互边界。"接口"一词与API非常容易混淆，台湾的**介面**更为贴切，既能指视觉层面的 UI 界面，也能指编程中的抽象协议，语义更为准确。
- **句柄**（handle）：原意是"把手、操作凭证"。"句柄"是生硬的音译，毫无语义可言。若译作**操作符**或**资源凭证**，理解成本会大幅降低。

## 优秀的翻译

好的翻译在音、形、义之间找到平衡，既贴近原文，又赋予新的生命力。

- **可口可乐**（Coca-Cola）：音译保留了原文的节奏感，"可口"与"可乐"又分别传达了"美味"与"愉悦"的正面联想，堪称商业译名的经典之作。
- **奔驰**（Mercedes-Benz）：取"Benz"的音，同时赋予"奔驰疾驰"的动感意象，与汽车品牌的气质高度契合。
- **鼠标**（Mouse）：形象的意译，抓住了鼠标外形似老鼠、连线如尾巴的特征，即便是初次接触的人也能瞬间理解。
- **云计算**（Cloud Computing）：将抽象的分布式网络比喻为"云"，既直观又富有诗意，远比"分布式远程计算"更易于大众传播。
