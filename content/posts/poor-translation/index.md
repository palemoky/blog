好的翻译讲究信、达、雅，让读者顾名思义、一目了然；糟糕的翻译则南辕北辙，令人不知所云。技术领域尤其如此——一个生硬的译名，往往比原文还难懂。

## 糟糕的翻译

- **抬头**（title）：发票上的 title 指的是接收方名称。而"抬头"在汉语里首先让人想到"抬起头"这个动作，与"接收方"毫无关联，初次接触的人往往一头雾水。
- **缺省值**（default）：译者想表达的是"缺少、省略时所取的值"，但"缺省"二字生僻拗口，大多数人很难立刻反应过来。相比之下，**默认值**要自然、直观得多。
- **鲁棒性**（robust）："鲁棒"是纯粹的音译，既无字面意义，也无联想空间，堪称技术翻译中的反面典型。**健壮性**才是更贴切的译法——既传达了"稳健、不易崩溃"的含义，又符合中文的构词习惯。
- **宏**（macro）：英文中 macro 与 micro 相对，而"宏"字在中文里多与"宏大、宏观"相关联，无法准确传达它的技术含义。更棘手的是，"宏"在不同场景下的行为差异很大，一个模糊的译名只会加重理解负担：

  | 场景         | 行为               |
  | ------------ | ------------------ |
  | Vim / Office | 操作录制与回放     |
  | C 语言       | 编译期的文本替换   |
  | Rust         | 语法层面的代码展开 |

- **内存**（memory）：memory 的核心特性是易失性——断电即清空，与硬盘的持久存储截然不同。但"内存"只强调了"机器内部的存储"，完全遮蔽了这一关键属性。台湾译作**记忆体**，更能体现数据的临时性。
- **接口**（interface）：interface 的字面意思是"交界面"，描述的是两个系统之间的交互边界。"接口"一词很容易与 API 混淆，台湾译作**介面**则更为贴切：既能指视觉层面的用户界面，也能指编程中的抽象协议，语义更准确。
- **句柄**（handle）：原意是"把手"，引申为操作资源的凭证。"句柄"二字字面晦涩，几乎无法从中读出任何含义。若译作**资源凭证**，理解成本会大幅降低。
- **套接字**（socket）：socket 原意是"插座"，这个比喻很形象，"套接字"却晦涩难懂。若译作**插座**，则更直观易懂。
- **哈希**（hash）：这是纯音译。"散列"能说明它把数据打散映射的特点，比"哈希"更好。
- **信号量**（semaphore）：原意是"旗语"。"信号量"读起来像是一个数值，看不出它是用来控制并发访问的。
- 一听（tin）：音译，读者完全看不出它和罐头有关系。
- 一打（dozen）：音译，读者完全看不出它和十二个一组的关系。

## 优秀的翻译

好的翻译能在音、形、义之间找到平衡，既贴近原文，又赋予新的生命力。

- **可口可乐**（Coca-Cola）：音译保留了原文的节奏感，"可口"与"可乐"又分别带来"美味"与"愉悦"的正面联想，堪称商业译名的经典之作。
- **赛百味**（Subway）：音译保留了原文的节奏感，"赛"与"百味"分别带来"竞技"与"丰富口味"的正面联想，既贴近原文，又易于记忆。
- **优步**（Uber）：音译保留了原文的节奏感，"优"与"步"分别带来"优秀"与"步伐"的正面联想，既贴近原文，又易于记忆。
- **宜家**（IKEA）：出自《诗经》"之子于归，宜其室家"。
- **露华浓**（Revlon）：出自李白"云想衣裳花想容，春风拂槛露华浓"。
- **奔驰**（Mercedes-Benz）：取 Benz 之音，同时赋予"奔腾疾驰"的动感意象，与汽车品牌的气质高度契合。
- **鼠标**（mouse）：形象的意译，抓住了它外形似老鼠、连线如尾巴的特征，即便初次接触也能瞬间理解。
- **云计算**（cloud computing）：把抽象的分布式网络比作"云"，既直观又富有诗意，远比"分布式远程计算"更易于大众传播。

## 产品命名

同样的道理也适用于产品命名：一个好名字能让人过目不忘，一个坏名字则需要反复解释。

### 优秀的产品名

- 淘宝：取"淘宝贝"之意，把逛街时沙里淘金的乐趣装进了名字，购物平台的定位一目了然
- SpaceX：Space 直指业务，X 象征未知与探索，简短有力，充满想象空间
- Tesla：致敬"交流电之父"尼古拉·特斯拉，与电动车的产品特性非常契合
- Faraday Future：致敬发现电磁感应的法拉第，电动机的原理正源于此，再配上 Future，电动车与未来感兼具
- 字节跳动：用计算机的基本单位"字节"加上充满活力的"跳动"，既体现了科技感，又富有动感。
- 抖音/TikTok：主打年轻用户群体，名字足够时尚
- 今日头条：名字简洁明了，直接体现了产品的核心功能——提供新闻资讯。
- 剪映：名字简洁明了，直接体现了产品的核心功能——剪辑视频。
- 零一万物：0 和 1 构成数字世界的一切
- 地平线：地平线是视野的尽头，也是远方的起点，契合自动驾驶"看得更远"的愿景
- 寒武纪：寒武纪是地球生命大爆发的时期，寓意 AI 芯片将引爆智能的"寒武纪大爆发"
- 追光动画：动画本就是光影的艺术，"追光"又有追逐梦想之意，一语双关
- 商汤：取自商朝开国君主商汤，其盘铭"苟日新，日日新，又日新"正契合科技公司不断创新的追求
- 蚂蚁搬家：非常形象，便于传播
- 曹操出行：呼应俗语"说曹操，曹操到"，体现了出行的便捷
- Google：源自 googol（10 的 100 次方），寓意海量信息，后来更成了"搜索"的代名词
- 飞书：作为 IM 产品，与"飞鸽传书"相呼应，体现了即时通讯的便捷

### 糟糕的产品名

有意思的是，"字节跳动"这个公司名很有科技感，旗下不少产品的名字却随意得多：它们大多取自日常物品，要靠后缀才能交代产品是做什么的。

- 豆包：过于口语化，无法顾名思义
- 红果短剧："红果"与短剧毫无关联，全靠后缀"短剧"交代产品是做什么的
- 汽水音乐：与红果短剧如出一辙，"汽水"和音乐毫不相干，去掉"音乐"二字就不知所云
- 扣子：作为 AI 智能体开发平台，名字却是衣服上的纽扣，既看不出 AI，也看不出开发

其他公司的名字则各有各的问题：

- 文心一言：过于文绉绉，作为面向大众的产品难以普及
- 通义千问：与文心一言问题相同，且有些拗口，如今大家几乎都只叫它"千问"
- 小米：与日常食物同名，和公司的产品八竿子打不着

### 各有利弊

- 滴滴：好处是公司名与产品高度绑定，一听就知道是打车；坏处也在于绑定太强，拓展到其他领域时就显得不太恰当
