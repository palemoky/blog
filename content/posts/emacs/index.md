Emacs 的功能大致可以分成这几块：

- **基础操作**：按键写法、缓冲区与窗口、帮助系统，是使用其他所有功能的前提
- **Org mode**（内置）：用纯文本写大纲，并在此基础上发展出一整套工具
  - 待办与日程：用 TODO、优先级、标签和日期管理任务，Agenda 能把多个文件里的任务汇总到一处查看
  - Capture：随时把想法或任务记到指定文件，不打断手头的工作
  - Babel：在笔记中嵌入并运行代码块，类似 Jupyter Notebook，但支持几乎所有编程语言
  - org-roam（第三方包）：用双向链接组织笔记，类似 Obsidian
- **Magit**（第三方包）：Git 客户端，被公认为 Emacs 的杀手级应用，终端里的 Lazygit 与它思路相近
- **TRAMP**（内置）：像编辑本地文件一样，直接编辑远程服务器或容器里的文件
- **Dired**（内置）：文件管理器，可以先标记多个文件，再批量重命名、移动或删除，终端里的 yazi 与它类似

另外，[Doom Emacs](https://github.com/doomemacs/doomemacs) 并不是某项功能，而是一套预先配好的 Emacs 发行版（同类的还有 Spacemacs）。它集成了上面这些包，并默认启用 Vim 风格的按键，适合不想从零开始折腾配置的人。用过 LazyVim 的话会很容易上手：两者都以空格作为 leader 键，按下后会弹出菜单，提示接下来可以按哪些键。

## 基础操作

### 按键写法

Emacs 文档里的按键用缩写表示，对应关系如下：

| Emacs 写法 | Windows / Linux | macOS                |
| ---------- | --------------- | -------------------- |
| `C-x`      | `Ctrl+x`        | `Ctrl+x`             |
| `M-x`      | `Alt+x`         | `Option+x`           |
| `S-`       | `Shift`         | `Shift`              |
| `RET`      | `Enter`         | `Return`             |
| `SPC`      | 空格            | 空格                 |

`C-x C-s` 表示先按 `Ctrl+x`，松开后再按 `Ctrl+s`。macOS 终端里要让 `Option` 充当 `Meta`，需要打开终端的相应设置（Ghostty 中是 `macos-option-as-alt = true`，见[常用工具]({{< relref "/posts/daily-tools/index.md#ghostty" >}})）。

### 前缀键

Emacs 的快捷键大多由前缀键开头，可以把前缀理解成一级「菜单」，按下后再选具体操作。

`C-x` 下是文件、窗口和缓冲区（buffer，大致可以理解为打开的文件）相关的操作：

| 按键      | 作用                                  |
| --------- | ------------------------------------- |
| `C-x C-f` | 打开文件（find file）                 |
| `C-x C-s` | 保存（save）                          |
| `C-x C-w` | 另存为（write）                       |
| `C-x C-c` | 退出 Emacs                            |
| `C-x b`   | 切换缓冲区（buffer）                  |
| `C-x k`   | 关闭缓冲区（kill buffer）             |
| `C-x 2`   | 上下拆分窗口                          |
| `C-x 3`   | 左右拆分窗口                          |
| `C-x 0`   | 关闭当前窗口                          |
| `C-x 1`   | 只保留当前窗口                        |

`C-c` 通常留给各个模式和插件使用，后面 Org mode 的快捷键大多以它开头。

### 不用死记，让 Emacs 自己告诉你

Emacs 内置了完整的帮助系统，忘了就查，这是最值得记住的一组键：

| 按键                 | 作用                                 |
| -------------------- | ------------------------------------ |
| `C-h k`，再按某个键  | 查看这个键执行什么命令               |
| `C-h w`，再输入命令名 | 查看这个命令绑定在哪个键上          |
| `C-h b`              | 列出当前所有按键绑定                 |
| `M-x`，再输入命令名  | 不记得快捷键时，直接按名字执行命令   |

### 常用操作

| 按键                   | 作用                                             |
| ---------------------- | ------------------------------------------------ |
| `C-g`                  | 取消当前操作，按错键时先按它                     |
| `C-/` / `C-x u`        | 撤销                                             |
| `C-n` / `C-p`          | 下一行 / 上一行                                  |

## Org mode

[Org mode](https://orgmode.org/) 文件以 `.org` 结尾，用 `*` 的个数表示标题层级，下面所有功能都建立在这个大纲结构上。

### 大纲

| 按键                   | 作用                                             |
| ---------------------- | ------------------------------------------------ |
| `TAB`（光标在标题上）  | 折叠 / 展开当前标题                              |
| `S-TAB`                | 整个文件在「全部折叠 / 只看标题 / 全部展开」间切换 |
| `M-RET`                 | 在下方新建一个同级标题                       |
| `M-→` / `M-←`           | 把标题降一级 / 升一级                        |
| `M-↑` / `M-↓`           | 把整个标题（连同子项）上移 / 下移            |

### 待办

| 按键                    | 作用                                         |
| ----------------------- | -------------------------------------------- |
| `C-c C-t` 或 `S-→` / `S-←` | 在 `TODO` → `DONE` → 无 之间循环切换      |
| `C-c ,` 然后 `A` / `B` / `C` | 设置优先级，按 `SPC` 则删除优先级       |
| `C-c C-q`               | 给当前标题设置标签，输入后按 `RET`（子标题会继承标签） |

#### 子任务进度

在父任务标题末尾加上 `[/]` 或 `[%]`，子任务的状态一变，进度就会自动更新：

```org
* TODO 搬家 [1/3]
** DONE 找房子
** TODO 打包
** TODO 退押金
```

把 `[/]` 换成 `[%]`，显示的就是 `[33%]`。

#### 复选框

一些零碎的小事不值得单独建一个标题，比如购物清单，用复选框列表就够了。父级标题同样可以加 `[/]` 统计进度：

```org
* 购物清单 [1/3]
- [X] 牛奶
- [ ] 鸡蛋
- [ ] 面包
```

| 按键      | 作用                                                   |
| --------- | ------------------------------------------------------ |
| `C-c C-c` | 光标在复选框所在行时，勾选 / 取消勾选                  |
| `M-S-RET` | 新建一个带复选框的列表项                               |
| `M-RET`   | 新建一个普通列表项（不带复选框，需要手动输入 `[ ]`）   |

### 稀疏树

稀疏树（sparse tree）会折叠掉无关内容，只露出匹配的任务。

| 按键       | 作用                           |
| ---------- | ------------------------------ |
| `C-c / t`  | 只显示所有 `TODO` 任务         |
| `C-c / m`  | 按标签或条件筛选，写法见下表   |
| `C-c C-c`  | 清除筛选留下的高亮             |
| `S-TAB`    | 重新展开整个文件               |

`C-c / m` 的筛选写法：

| 输入              | 含义                                          |
| ----------------- | --------------------------------------------- |
| `紧急`            | 带「紧急」标签                                |
| `电脑+紧急`       | 同时带这两个标签                              |
| `电脑\|手机`      | 带其中任意一个标签                            |
| `电脑-紧急`       | 带「电脑」但不带「紧急」                      |
| `PRIORITY="A"`    | 优先级为 A                                    |
| `+紧急/TODO`      | 带「紧急」且状态仍是 `TODO`（排除已完成的）   |

> 稀疏树只作用于当前文件；要跨多个文件筛选，需要用 Agenda。

### 日期

Org 的任务日期分两种：`SCHEDULED`（计划哪天开始做）和 `DEADLINE`（最晚哪天完成）。

| 按键            | 作用                        |
| --------------- | --------------------------- |
| `C-c C-s`       | 设置计划日期（SCHEDULED）   |
| `C-c C-d`       | 设置截止日期（DEADLINE）    |
| `C-u C-c C-s`   | 删除计划日期                |
| `C-u C-c C-d`   | 删除截止日期                |
| `C-c .`         | 插入活动时间戳 `<...>`，会出现在 Agenda 里 |
| `C-c !`         | 插入非活动时间戳 `[...]`，只做记录，不会出现在 Agenda 里 |

弹出日期选择后，可以直接输入简写（假设今天是 2026-09-29 周二）：

| 输入             | 结果                    |
| ---------------- | ----------------------- |
| `.` 或直接 `RET` | 今天                    |
| `+1`             | 明天                    |
| `+3`             | 3 天后                  |
| `+2w`            | 2 周后                  |
| `fri`            | 下一个周五（10-02）     |
| `10-15`          | 今年 10 月 15 日        |
| `10-1 14:00`     | 10 月 1 日下午 2 点     |
| `+1 9:30`        | 明天早上 9:30           |

#### 重复任务

在日期后面加上重复标记，任务标记为 `DONE` 时会自动顺延到下一次，例如 `SCHEDULED: <2026-10-05 Mon +1w>`。

| 标记    | 下次日期怎么算                                     | 适合                             |
| ------- | -------------------------------------------------- | -------------------------------- |
| `+1w`   | 在原日期上加 1 周；漏了几次就要逐次补完             | 每次都不能落下的事，例如周报     |
| `++1w`  | 在原日期上按周往后推，直到落在今天之后（星期几不变）| 漏了就算了、不用补的事，例如周日倒垃圾 |
| `.+1w`  | 从完成那天起算 1 周后                              | 间隔比日期重要的事，例如理发、换床单 |

> 单位：`h` 小时、`d` 天、`w` 周、`m` 月、`y` 年。
  

#### 提前提醒

在 `DEADLINE` 后面加 `-3d`，Agenda 会从截止日前 3 天开始提醒（默认是提前 14 天）。可以和重复标记一起用：

```org
DEADLINE: <2026-10-15 Thu +1m -3d>
```

表示每月 15 日截止，每次提前 3 天提醒。

#### 习惯追踪

每天锻炼、读书这类习惯，可以交给 org-habit 追踪。它是 Org 自带的模块，但默认不加载，需要在配置里打开：

```elisp
(with-eval-after-load 'org
  (require 'org-habit))
```

习惯本质上是一个带重复标记的任务，只是多了一个 `STYLE` 属性。可以按 `C-c C-x p` 添加这个属性，也可以直接手写：

```org
* TODO 跑步
SCHEDULED: <2026-09-29 Tue .+1d>
:PROPERTIES:
:STYLE:    habit
:END:
```

重复标记通常用 `.+`，从上次完成那天起算。之后 Agenda 里这个任务旁会多出一条彩色的打卡记录，标出哪些天完成了、哪些天漏了，连续坚持了多久一目了然。

### Agenda

Agenda 会扫描指定的 Org 文件，把其中的任务按日期汇总到同一个视图里，告诉你今天和这周要做什么。

要扫描哪些文件由 `org-agenda-files` 决定。原生 Emacs 默认没有给 Agenda 绑定快捷键，官方手册推荐绑定到 `C-c a`，下文沿用这个绑定：

```elisp
(setq org-agenda-files '("~/org/"))  ; 扫描该目录下所有 .org 文件
(global-set-key (kbd "C-c a") #'org-agenda)
```

按 `C-c a` 会弹出菜单，常用的是 `a`（本周日程）和 `t`（所有 TODO 列表）。进入 Agenda 后，可以直接用单个按键操作。

#### 浏览

| 按键         | 作用                                   |
| ------------ | -------------------------------------- |
| `n` / `p`    | 下一行 / 上一行                        |
| `f` / `b`    | 往后 / 往前翻一页（按周显示时即一周）  |
| `.`          | 回到今天                               |
| `d` / `w`    | 切换成按天 / 按周显示                  |
| `j`          | 跳到指定日期                           |
| `r` 或 `g`   | 刷新，在原文件里改过内容后使用         |
| `q`          | 退出 Agenda                            |

#### 操作任务

| 按键                    | 作用                                                 |
| ----------------------- | ---------------------------------------------------- |
| `t`                     | 切换 TODO 状态，相当于原文件里的 `C-c C-t`           |
| `,`                     | 设置优先级                                           |
| `:`                     | 设置标签                                             |
| `C-c C-s` / `C-c C-d`   | 设置计划日期 / 截止日期                              |
| `>`                     | 把任务改到另一天，按提示输入新日期（今天做不完时常用） |
| `S-→` / `S-←`           | 把任务往后 / 往前挪一天（终端不识别这两个键时，改用 `>`） |
| `RET`                   | 在当前窗口跳到原文件里的这条任务                     |
| `TAB`                   | 在另一个窗口打开原文件，光标也跳过去                 |
| `SPC`                   | 在另一个窗口显示原文件，光标仍留在 Agenda 里         |

#### 筛选

| 按键 | 作用                                       |
| ---- | ------------------------------------------ |
| `/`  | 按标签筛选，例如只看带「电脑」标签的任务   |
| `\|` | 清除所有筛选                               |

#### 每日用法

1. 早上按 `C-c a a`，看看今天要做什么、哪些截止日期快到了。
2. 今天做不完的任务，按 `>` 改到别的日子，别让它一直堆在过期列表里。
3. 做完一件，就在 Agenda 里按 `t` 标记完成。
4. 每周按一次 `C-c a t`，把所有 TODO 过一遍，给该做的任务排上日期。

### Capture

想到一件事时，按 `C-c c` 选一个模板，在弹出的小窗口里写下来，保存后会回到原来的工作，不用切换文件，也不打断思路。记下的内容先统一放进一个「收件箱」文件，之后再集中整理。

和 Agenda 一样，快捷键和模板都要自己配置，下面的 `t`、`n` 就是模板对应的按键：

```elisp
(global-set-key (kbd "C-c c") #'org-capture)
(setq org-capture-templates
      '(("t" "待办" entry (file "~/org/inbox.org") "* TODO %?")
        ("n" "笔记" entry (file "~/org/inbox.org") "* %?\n%a")))
```

模板里的 `%?` 表示窗口弹出后光标所在的位置，`%a` 会自动插入一个链接，指向按下 `C-c c` 时所在的位置。

在弹出的 Capture 窗口里：

| 按键      | 作用                                             |
| --------- | ------------------------------------------------ |
| `C-c C-c` | 保存并关闭窗口，回到原来的工作                   |
| `C-c C-k` | 放弃，不保存                                     |
| `C-c C-w` | 保存，并直接移到指定标题下，不经过收件箱         |

`%a` 链接很实用：看代码或文档时按 `C-c c n` 记一条笔记，笔记里会自动带上指向当前位置的链接，以后把光标放在链接上按 `C-c C-o`，就能跳回原处。

#### Refile：整理收件箱

Refile 指把任务从收件箱移到它该去的地方：

| 按键      | 作用                                             |
| --------- | ------------------------------------------------ |
| `C-c C-w` | 把当前任务（连同子项）移到另一个标题下           |

默认只能移到当前文件的一级标题下。想移到 Agenda 里所有文件的一、二级标题下，可以加上：

```elisp
(setq org-refile-targets '((org-agenda-files :maxlevel . 2)))
```

> 在 Agenda 里同样可以按 `C-c C-w`：用 `C-c a t` 列出所有 TODO，收件箱里的任务也在其中，可以直接逐条移走。

#### 工作流

把 Capture、Refile 和 Agenda 串起来，就是一套完整的任务管理流程：

```text
想到一件事 ──C-c c────> 收件箱
                        |
                        |  每天或每周整理：C-c C-w 移到对应标题下，排上日期和优先级
                        ▼
每天早上   ──C-c a a──> 查看今天的任务 ──t──> 完成
```

### 计时

想知道每件事实际花了多少时间，可以给任务计时。计时期间，Emacs 底部的模式栏会一直显示已用时间：

| 按键          | 作用                                              |
| ------------- | ------------------------------------------------- |
| `C-c C-x C-i` | 开始给当前任务计时（clock in）                    |
| `C-c C-x C-o` | 停止计时（clock out）                             |
| `C-c C-x C-j` | 跳回正在计时的任务                                |
| `C-c C-x C-d` | 在每个标题后显示累计用时，按 `C-c C-c` 清除       |
| `C-c C-x C-r` | 插入一张用时统计表                                |

在 Agenda 里也能直接操作：`I` 开始计时，`O` 停止，`R` 在视图底部显示用时统计。

每次计时的起止时间都会记在任务下方的 `:LOGBOOK:` 抽屉里，默认折叠，不会弄乱正文。

### 进阶配置

以下配置都写在 `init.el` 里（Doom Emacs 写在 `config.el` 里）。

#### 自定义 TODO 状态

默认只有 `TODO` 和 `DONE` 两种状态，可以按自己的习惯扩展：

```elisp
(setq org-todo-keywords
      '((sequence "TODO(t)" "DOING(i)" "WAITING(w@/!)" "|" "DONE(d!)" "CANCELED(c@)")))
```

各部分的含义：

| 写法       | 含义                                                                 |
| ---------- | -------------------------------------------------------------------- |
| `\|` 左边  | 未完成的状态                                                         |
| `\|` 右边  | 已结束的状态，`CANCELED` 也算结束，不会再出现在 TODO 列表里          |
| `(t)`      | 用 `C-c C-t` 切换状态时，按这个字母直接跳到该状态                    |
| `!`        | 切换到该状态时，自动记录时间                                         |
| `@`        | 切换到该状态时，弹出窗口让你写一条备注，比如「等张三回复报价」       |
| `w@/!`     | 进入 `WAITING` 时写备注，离开时记录时间                              |

再加两项配置，让记录更整洁、状态更醒目：

```elisp
;; 状态变更的时间和备注统一收进可折叠的 :LOGBOOK: 抽屉，不把正文弄乱
(setq org-log-into-drawer t)

;; 给不同状态设置不同颜色
(setq org-todo-keyword-faces
      '(("DOING"    . (:foreground "yellow" :weight bold))
        ("WAITING"  . (:foreground "magenta" :weight bold))
        ("CANCELED" . (:foreground "gray"))))
```

#### 自定义 Agenda 视图

把每天最常看的几类任务拼进一个视图，早上打开一次就能看全：

```elisp
(setq org-agenda-custom-commands
      '(("d" "今日总览"
         ((agenda "" ((org-agenda-span 'day)))
          (todo "DOING"
                ((org-agenda-overriding-header "进行中")))
          (tags-todo "PRIORITY=\"A\""
                     ((org-agenda-overriding-header "高优先级")))
          (tags-todo "inbox"
                     ((org-agenda-overriding-header "收件箱（待整理）")))))
        ("w" "等待中" todo "WAITING")))
```

之后按 `C-c a d` 打开「今日总览」，按 `C-c a w` 查看所有等待中的任务。

「收件箱」一栏按 `inbox` 标签筛选，所以要在 `inbox.org` 开头加一行，让文件里的所有任务都带上这个标签：

```org
#+FILETAGS: :inbox:
```

#### 归档已完成的任务

任务做完后可以归档，从原文件里移走，但不会删除：

| 按键                          | 作用                                                   |
| ----------------------------- | ------------------------------------------------------ |
| `C-c C-x C-a`（在 Org 文件里）| 把当前任务移到同目录下的 `<文件名>.org_archive`        |
| `$`（在 Agenda 里）           | 同上                                                   |

如果不想频繁归档，也可以让 Agenda 直接隐藏已完成的任务：

```elisp
(setq org-agenda-skip-scheduled-if-done t)
(setq org-agenda-skip-deadline-if-done t)
```

#### 还可以继续探索

- **属性与列视图**：给任务添加预估工时等字段，以表格形式查看
- **手机同步**：通过网盘同步 Org 文件，在手机上用 beorg（iOS）或 Orgzly（Android）查看和编辑

## Doom Emacs

从零配置 Emacs 很容易陷进去：选包、配按键、调性能，折腾好几天还没开始干正事。[Doom Emacs](https://github.com/doomemacs/doomemacs) 把这些都做好了：启动快，默认使用 Vim 按键，上面讲的 Org mode、Magit、Dired 等功能也都已配好，装完就能直接用。

如果你熟悉 LazyVim，上手 Doom 几乎没有门槛。两者的设计思路如出一辙：都以空格作为 leader 键，按下后弹出菜单提示后续按键，键位也大多按英文首字母组织，比如 `SPC f` 管文件、`SPC b` 管缓冲区、`SPC g` 管 Git。

### 安装

先装好 Emacs（建议 29 或以上）和几个依赖，再克隆 Doom 并运行安装脚本：

```bash
brew install --cask emacs
brew install git ripgrep fd

git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.config/emacs
~/.config/emacs/bin/doom install
```

之后可以把 `~/.config/emacs/bin` 加进 `PATH`，就能在任意位置直接运行 `doom` 命令。

### 配置文件

Doom 的个人配置都在 `~/.config/doom/` 目录下，一共三个文件：

| 文件          | 用途                                                       |
| ------------- | ---------------------------------------------------------- |
| `init.el`     | 开启或关闭模块，比如 `org`、`magit`、`evil`，取消注释即开启 |
| `config.el`   | 个人配置，前文所有 `init.el` 里的配置都写到这里             |
| `packages.el` | 安装模块之外的第三方包                                     |

修改 `init.el` 或 `packages.el` 后，要运行一次 `doom sync` 再重启 Emacs 才会生效；只改 `config.el` 的话，直接重启即可。

### 常用命令

| 命令           | 作用                                             |
| -------------- | ------------------------------------------------ |
| `doom sync`    | 按配置安装、删除包，改完 `init.el` 后必须运行    |
| `doom upgrade` | 升级 Doom 本身和所有包                           |
| `doom doctor`  | 检查缺少的依赖和常见配置问题，出问题时先跑它     |
| `doom env`     | 重新读取 shell 的环境变量，比如修改 `PATH` 之后  |

### SPC 键

Doom 默认启用 evil（Emacs 里的 Vim 模拟），`i` 进入插入模式，`Esc` 回到普通模式，`:w`、`dd` 这些 Vim 操作都能用。

在普通模式下按 `SPC`，会弹出一个菜单列出所有后续按键，按键大多是英文单词的首字母，不用刻意背：

| 按键             | 作用                                   | 对应原生按键   |
| ---------------- | -------------------------------------- | -------------- |
| `SPC .`          | 打开文件                               | `C-x C-f`      |
| `SPC f r`        | 打开最近的文件                         |                |
| `SPC SPC`        | 在当前项目里查找文件                   |                |
| `SPC b b`        | 切换缓冲区                             | `C-x b`        |
| `SPC b k`        | 关闭缓冲区                             | `C-x k`        |
| `SPC w v` / `SPC w s` | 左右 / 上下拆分窗口               | `C-x 3` / `C-x 2` |
| `SPC w h/j/k/l`  | 切换到左 / 下 / 上 / 右边的窗口        |                |
| `SPC :`          | 按名字执行命令                         | `M-x`          |
| `SPC h`          | 帮助系统，比如 `SPC h k` 查看按键      | `C-h`          |
| `SPC s p`        | 在整个项目里搜索文本                   |                |
| `SPC g g`        | 打开 Magit                             |                |
| `SPC q q`        | 退出 Emacs                             | `C-x C-c`      |

`SPC m` 是当前模式专属的菜单，比如在 Org 文件里按 `SPC m`，会列出 Org 的所有操作。

### 在 Doom 里用 Org mode

前文讲的 `C-c` 开头的按键在 Doom 里照常可用，另外还有更顺手的 `SPC` 入口：

| 按键      | 作用                                    |
| --------- | --------------------------------------- |
| `SPC X`   | Capture，相当于前文的 `C-c c`           |
| `SPC o A` | 打开 Agenda 菜单，相当于前文的 `C-c a`  |
| `SPC m`   | Org 文件里的操作菜单                    |

Doom 默认把 Org 文件放在 `~/org/`，并自动把这个目录设为 Agenda 的扫描范围，还自带了几个 Capture 模板，所以前文的 `org-agenda-files` 和快捷键绑定都可以省掉。

要注意的是，Doom 会在 Org 加载时写入自己的默认值，直接 `setq` 的配置可能会被覆盖。Org 相关的配置要包在 `after! org` 里：

```elisp
;; config.el
(setq org-directory "~/org/")  ; 这一行例外，要在 Org 加载前设置，所以放在外面

(after! org
  (setq org-todo-keywords
        '((sequence "TODO(t)" "DOING(i)" "WAITING(w@/!)" "|" "DONE(d!)" "CANCELED(c@)")))
  (setq org-log-into-drawer t))
```

### 不想用 Vim 按键？

在 `init.el` 里注释掉 `evil` 这一行，运行 `doom sync` 后重启，就会变回原生的 Emacs 按键，前文所有 `C-x`、`C-c` 快捷键都能直接用。Doom 的其他好处，比如启动速度和预装的模块，都会保留下来。
